# Goddy Graphix

Goddy Graphix is a professional graphic design portfolio and client management platform designed to showcase creative work and streamline service inquiries.

## Features

- **Professional Portfolio Showcase**: A high-impact visual gallery designed to highlight graphic design projects with category-based filtering.
- **Secure Admin Dashboard**: A robust management panel that allows administrators to add new pieces, delete old ones, and toggle the visibility of specific items in real-time.
- **Unified Service Requests**: An integrated client inquiry system where potential customers can request specific services and provide project details.
- **Instant Notification System**: Automated alerts for every client submission, delivered instantly via Telegram and Email to ensure no inquiry goes unanswered.
- **Dynamic Content Control**: Full control over portfolio metadata, including titles, categories, and descriptions, directly from the web interface.
- **Advanced Security**: Built-in protection featuring login rate limiting, secure cookie-based session management, and encrypted password storage.
- **Automated Media Handling**: Seamless image management for portfolio uploads with optimized storage and delivery.
- **Service Management**: Admin-controlled announcements and platform settings to keep clients informed of latest updates.
